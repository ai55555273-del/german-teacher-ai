# German Teacher AI

نظام بسيط لإنشاء محتوى تعليمي للغة الألمانية وتجهيز فيديوهات قصيرة ونشرها عبر Meta باستخدام GitHub Actions.

## الملفات
- `main.py` — إنشاء محتوى وفيديو قصير.
- `requirements.txt` — المكتبات المطلوبة.
- `.env.example` — أسماء المتغيرات السرية المطلوبة لاحقًا.
- `.github/workflows/post.yml` — التشغيل التلقائي عبر GitHub Actions.
- `.gitignore` — يمنع رفع الأسرار والملفات المؤقتة.

> ملاحظة: هذا الإصدار الأساسي لا يحتاج API مدفوع لتوليد المحتوى؛ المحتوى التعليمي يتم توليده من قوالب داخل البرنامج. ربط Meta يحتاج بيانات API من Meta، وقد تكون بعض صلاحيات/ميزات Meta خاضعة لشروط المنصة.

## التشغيل محليًا
```bash
pip install -r requirements.txt
python main.py
```
